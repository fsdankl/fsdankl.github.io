2. 앱에서 사용하는 기록

수업 진도, 학습 완료 여부, 문제 풀이와 오답·복습 기록, 저장한 표현, 소리 없이 학습 설정, 목소리 선택과 문장별 재생 속도를 사용자의 기기에 저장합니다. 이 기록은 학습을 이어가고 복습을 제공하기 위해 사용합니다. 앱은 회원가입이나 로그인을 요구하지 않습니다.

3. 수집·전송과 접근 권한

현재 버전은 학습 기록을 개발자의 서버로 전송하거나 제3자와 공유하지 않습니다. 수업·이미지·음원은 앱에 포함되어 오프라인으로 실행됩니다. 앱은 광고 SDK, 분석 SDK, 음성 인식 또는 녹음을 사용하지 않으며, 마이크·카메라·위치·연락처·광고 식별자에 접근하지 않습니다.

4. 백업과 가져오기

사용자가 ‘학습 기록 백업’을 선택하면 Android 파일 선택기를 통해 지정한 위치에 학습 기록 JSON 파일을 저장합니다. 사용자가 클라우드 문서 제공자를 선택한 경우 해당 제공자의 정책이 적용됩니다. ‘가져오기’는 사용자가 선택한 백업 파일만 읽으며, 기존 기록은 기기에 복구용으로 보관합니다. Android 시스템의 자동 백업과 기기 이전이 활성화되어 있으면 Android가 앱 내부 학습 기록을 백업·복원할 수 있습니다. 이 과정은 기기와 Google 계정 설정에 따르며 개발자는 해당 백업에 접근하지 않습니다.

5. 보관과 삭제

기기의 앱 저장공간에 학습 기록과 복구용 기록을 보관합니다. 기기 설정의 앱 저장공간에서 앱 데이터를 삭제하거나 앱을 제거하여 기기 내 기록을 삭제할 수 있습니다. 내보낸 백업 파일과 Android 시스템 백업은 각각 사용자가 선택한 저장 위치와 기기·Google 계정의 백업 설정에서 별도로 관리·삭제할 수 있습니다. 앱에는 서버 계정이 없으므로 계정 삭제 절차는 없습니다.
